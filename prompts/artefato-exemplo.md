# Artefato: exemplo (trocar)

> **Modelo.** Faça um arquivo destes para **cada** artefato do `modulo.json`, com o nome `artefato-<id>.md`.
> Apague este aviso e escreva as instruções do artefato real do seu módulo.

Este texto entra no campo `conteudoMarkdown` do artefato `exemplo` na saída JSON.

## O que a empresa recebe

Descreva em uma frase o que é este documento e para que o dono vai usá-lo (por exemplo: uma folha para colar no balcão, uma lista para preencher, uma política para assinar).

## Como escrever

- Comece com um título `##` e uma frase dizendo para que serve.
- Use listas curtas e, quando ajudar, uma tabela de poucas colunas.
- Deixe campos para a empresa preencher à mão como `_______` e marque com `[ ]` o que ela precisa decidir.
- Adapte os exemplos ao ramo **{{ramo}}** e ao porte **{{porte}}**.
- Linguagem do dia a dia: quem lê é o dono e a equipe, não um técnico.
- Nada de nome de empresa, CNPJ, endereço, site ou nome de pessoa — só o codinome, se precisar.
- Tamanho: o que cabe em uma ou duas folhas impressas.

## Estrutura sugerida

```markdown
## Título do artefato

Para que serve: …

### O que fazer
1. …
2. …

### Para preencher
| Item | Responsável | Quando |
|---|---|---|
| … | _______ | _______ |
```
